## 🚀 Publishing with GitHub Pages

1. Create a new **public** repository on GitHub (e.g. `lilys-holiday`)
2. Upload all files from this folder into the repository root
3. Go to **Settings → Pages**
4. Under **Source**, select `Deploy from a branch`
5. Choose **Branch: main** and folder **/ (root)**, then click **Save**
6. After a minute or two, your site will be live at:
   ```
   https://YOUR-USERNAME.github.io/lilys-holiday/
   ```
7. Share that link with Lily before she travels!

> **Tip:** All files must be in the **root** of the repository (not in a subfolder) for the links between pages to work correctly.
